**FreshFinder – Food Desert Locator**

A MERN stack capstone project that helps users search for an address and determine if it falls within a designated food desert. Designed to promote food accessibility and raise awareness about food insecurity.

**About the Project**

FreshFinder is a full-stack web application built to help users:

Search for an address

Determine if that location lies within a USDA-defined food desert

Discover nearby grocery stores

Get walking directions to those stores

This capstone project combines mapping technology, geospatial data, and user-friendly design to support community engagement and access to healthy food options.

**Tech Stack**

MongoDB Atlas – Stores food desert polygon coordinates

Express.js – Backend API and server logic

React.js – Frontend interface

Node.js – Server runtime

Google Maps API – Geolocation, places search, and directions

Mongoose – ODM for MongoDB

**Key Features**

Address search

Food desert detection using custom polygon data

Custom map markers for nearby grocery stores

Walking directions from searched address to selected store

Responsive and intuitive user interface
